# Linux+ objectives

The full 16-module hands-on curriculum is already built in. This folder is
optional.

If you want the original CompTIA XK0-005 objectives available for reference
and alignment checks, drop the official PDF or a text copy here and run:

```bash
python3 main.py exam scan
python3 main.py exam objectives
```

The curriculum mapping in `curriculum/syllabus.py` already labels every module
with the relevant Linux+ domain, so the pack works without the source PDF.
